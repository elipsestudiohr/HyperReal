1. Executive Summary

Hyper Real Estate (HRE) is an enterprise-grade, collaborative architectural visualization platform engineered by Elipse Studio. Built on Unreal Engine 5.6, the platform enables prospective buyers, architects, and sales agents worldwide to tour photorealistic 3D architectural spaces collaboratively across Meta Quest standalone VR headsets and Windows PC workstations.

The Core Challenge
High-fidelity ArchViz requires multi-gigabyte models featuring dense geometry and high-resolution textures. Deploying directly to standalone mobile VR hardware imposes strict APK size limits, tight mobile RAM budgets, and full app reinstalls for every new property. HRE solves this by streaming modular PAK assets dynamically from the cloud while coordinating cross-platform avatars and spatial voice in real time.

3. Core Subsystems & Implementation Details

3.1 Dynamic DLC & Runtime PAK Streaming Pipeline (UDLCManager)

The base application is a lightweight shell (~480 MB). Heavy 3D assets are mounted dynamically at runtime without engine serialization faults:

// Architectural Implementation: Dynamic Mounting & Synchronous Registry Sync
bool UDLCManager::MountChunk(int32 ChunkId)
{
    FString PakFilePath = GetChunkFilePath(ChunkId);
    FPakPlatformFile* PakFileMgr = static_cast<FPakPlatformFile*>(
        FPlatformFileManager::Get().FindPlatformFile(TEXT("PakFile")));
    
    if (!PakFileMgr || !FPaths::FileExists(PakFilePath)) return false;

    int32 MountPriority = 1000 + ChunkId;
    FString AbsolutePakPath = FPaths::ConvertRelativePathToFull(PakFilePath);
    FString AbsoluteMountPoint = FPaths::ConvertRelativePathToFull(FPaths::ProjectDir());

    bool bMounted = PakFileMgr->Mount(*AbsolutePakPath, MountPriority, *AbsoluteMountPoint);
    if (bMounted)
    {
        MountedChunks.Add(ChunkId);
        // Force synchronous asset registry discovery for newly mounted PAK files
        FAssetRegistryModule& AssetRegistryModule = 
            FModuleManager::LoadModuleChecked<FAssetRegistryModule>("AssetRegistry");
        AssetRegistryModule.Get().ScanPathsSynchronous({TEXT("/Game/")}, true);
        OnMountComplete.Broadcast(ChunkId, true);
    }
    return bMounted;
}

3.2 Cross-Platform Multiplayer & Synchronization (APhotonManager)

  • Heterogeneous Locomotion: UVRPlayerReplicator handles 6DOF headset, controllers, and OpenXR hand poses. UFirstPersonReplicator synchronizes desktop PC users.
  • Bandwidth Compression: Unreliable delta transforms broadcast at 20Hz (50ms interval) with Hermite client-side interpolation. Reliable events handle matchmaking and room state.
  • Voice & Persistence: Agora RTC provides full-duplex spatial audio with hardware hot-swapping; Supabase RPC manages atomic room participant tracking.

4. Key Technical Challenges & Engineering Solutions

Challenge 1: Android VR Chromium SIGSEGV Crashes During Level Travel

Symptom: Fatal native segmentation fault inside Android's Chromium WebView thread during level loading with active 3D web widgets.

Solution: Engineered USafeWebBrowserWidget with two-stage teardown: clears URL to about:blank, detaches Slate bindings, and delays level travel by one frame.

Challenge 2: Asset Registry Desynchronization on Dynamically Mounted PAKs

Symptom: Dynamically mounted PAK levels failed in OpenLevel with Package Not Found.

Solution: Executed AssetRegistry.ScanPathsSynchronous({TEXT("/Game/")}, true) immediately following FPakPlatformFile::Mount().

Challenge 3: Blueprint Circular Dependencies & Async Thread Deadlocks

Symptom: Dynamic pawn spawning inside multiplayer delegates caused engine AsyncLoadingThread freezes.

Solution: Refactored all class declarations from hard references to soft class pointers (TSoftClassPtr<APawn>) resolved asynchronously.

Challenge 4: 3D Widget Raycast Desynchronization After Pawn Respawn

Symptom: VR raycasts failed to trigger hover/click events on 3D in-game menus after level transitions.

Solution: Developed UWidgetInteractionFixer to reset pointer indexes and force re-registration of all world widget collision channels upon pawn possession.

Enterprise Compliance, Privacy & Data Security

  • Zero PII Retention: No personally identifiable information (PII) is stored or tracked across sessions.
  • Ephemeral Transport Memory: Room instances, voice channels, and transform states reside strictly in volatile RAM and auto-prune upon disconnect.
  • Hardware Access Governance: Explicit system-level permission prompts for Quest eye-tracking and microphone arrays.
  • Encrypted Transport: All dynamic PAK chunks and API payloads utilize HTTPS/TLS with cryptographic integrity verification.
